# حرب المدينة — النسخة الكاملة (3 مراحل × 5 مستويات + حسابات + Firebase)

## التشغيل
1. فك الضغط عن الملف.
2. **ويندوز:** انقر مرتين على `RUN_GAME_WINDOWS.bat` (يحتاج Python). **ماك/لينكس:** `sh run_mac_linux.sh`.
3. يفتح المتصفح على `http://localhost:8080`.

> لا تفتح `index.html` بالنقر المزدوج: تسجيل الدخول وقاعدة البيانات لا يعملان من `file://` — لكن يمكنك اللعب «كضيف» بهذه الطريقة.

## إعداد Firebase (مرة واحدة) — المشروع `hassony-40479`
1. **Authentication ← Sign-in method:** فعّل **Email/Password** و **Google**.
2. **Authentication ← Settings ← Authorized domains:** `localhost` موجود افتراضياً؛ أضف نطاق موقعك إذا رفعت اللعبة على استضافة.
3. **Firestore Database:** أنشئ قاعدة بيانات (Production mode).
4. **Firestore ← Rules:** الصق محتوى `firestore.rules` ثم **Publish** (يسمح لكل لاعب بقراءة/كتابة بياناته فقط).
5. (اختياري) رفع اللعبة: `firebase deploy` من هذا المجلد (ملف `firebase.json` جاهز).

تُحفظ بيانات كل لاعب في المجموعة `players/{uid}`: التقدم والنجوم وأفضل نتيجة لكل مستوى والإحصائيات وإعدادات الأزرار. وعند انقطاع الإنترنت يُحفظ محلياً ثم يُزامَن لاحقاً.

## ما الجديد
- **3 مراحل:** المدينة ← **العاصفة** (مطر وبرق ورؤية محدودة) ← **الجليد** (ثلج وضباب وأرضية زلقة). كل مرحلة **5 مستويات**، والمستوى التالي يُفتح بإكمال السابق.
- **عالم أكبر:** 6400×6400 (حوالي 3 أضعاف المساحة السابقة) ومولَّد عشوائياً في كل مستوى.
- **30 عدواً في كل مستوى** يظهرون تدريجياً (تغيير الرقم: `PER_LEVEL` في الكود). المستوى يكتمل عند القضاء على الجميع، ويُمنح 1–3 نجوم حسب صحتك وسقوط الرفاق.
- **رفيقان (ياسر وعمر)** يتبعانك ويقاتلان؛ إذا سقط أحدهما يعود بعد 12 ثانية.
- **الواجهة:** تسجيل الدخول (بريد/Google/ضيف) ← القائمة الرئيسية (متابعة، اختيار المرحلة والمستوى، الإعدادات، تسجيل الخروج، مغادرة).
- **الإعدادات ← تعديل أماكن الأزرار:** اسحب أي زر لنقله، واستخدم المنزلق أو ‎+/−‎ لتكبيره/تصغيره، ويوجد منزلق لحجم كل الأزرار، وكل ذلك يُحفظ في حسابك. زر ⚙️ داخل اللعب يفتح الإعدادات.

## ملاحظة أمنية
مفاتيح `firebaseConfig` في تطبيقات الويب ليست سرية؛ الحماية الفعلية هي قواعد Firestore أعلاه. لا تغيّرها إلى `allow read, write: if true`.
